

# study_notes

学习笔记仓库

本仓库用于存放日常学习笔记，涵盖编程语言、工具软件和数据库等领域的知识。

## 目录

### 编程语言

- **Python** (`Python.md`) - Python 基础知识，包括语法、数据类型、控制结构等
- **JavaWeb** (`JavaWeb.md`) - HTML 与 CSS 网页开发基础

### 版本控制

- **Git 入门** (`Git-beginner.md`) - Git 基本操作流程与常用命令

### 数据库

- **MySQL** (`MySQL.md`) - SQL 语句、约束与查询操作

### 操作系统

- **Linux** (`Linux.md`) - Linux 基本命令、用户管理、权限配置与 Vim 编辑器

## 技术栈

- 笔记软件：[Obsidian](https://obsidian.md/)
- 版本控制：Git + [obsidian-git](https://github.com/denolehov/obsidian-git) 插件

## 使用说明

1. 使用 Obsidian 打开本仓库目录即可查看和编辑笔记
2. 笔记采用 Markdown 格式编写
3. 通过 obsidian-git 插件自动同步到 Gitee

## 笔记规范

- 章节层级清晰，使用有序列表编号
- 重要知识点用代码块标注
- 保持内容简洁，便于复习回顾

## 贡献

欢迎提交 Issue 或 Pull Request 完善笔记内容。
